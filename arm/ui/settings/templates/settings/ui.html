Optional Smart Title Matching

Optional local language-model reranking helps with abbreviations, typos, and ambiguous franchise titles. ARM sends the disc label and metadata search candidates (including available summaries) to your configured Ollama service. When disabled, ARM uses its standard matcher.

Ollama must be installed and reachable separately. ARM's base image does not include a model runtime or weights. Save the URL/model, then use Download model to pull the weights to Ollama; the download may be several gigabytes and use CPU/RAM. If the model is unavailable, ripping continues with standard matching.

Use the Ollama service name on a shared Docker network, or a reachable host address; localhost means the ARM container itself.

Model weights are installed on the configured Ollama service, not inside ARM.
